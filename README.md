# 读通鉴 · 本地阅读版

参考 https://www.dutongjian.com/ 的阅读布局，独立实现基本阅读功能。

## 使用

当前预览：http://127.0.0.1:5173/ 。

以后使用：双击「启动阅读器.command」，浏览器会打开阅读器。需要电脑已有 Python 3；当前电脑已具备。关闭终端窗口可停止服务。

## 已实现

- 资治通鉴、纪事本末、读通鉴论切换，卷目和年份目录，目录筛选，前后章节。
- 指定 EPUB 的繁体正文、胡三省注、校注、人名／地名／书名标记和异体字图片。
- 点击原文人名打开人物卡片：人物简介、相关段落分页、当前出现位置、命中高亮、全文与译文展开、点击卷目回到原文。
- 全文搜索，繁简通搜、精准／多词搜索、范围筛选、命中高亮、点击结果返回原文。
- 章节书签、段落收藏、批注新增／编辑／删除、收藏和批注列表回跳。
- 阅读进度及阅读时长，在当前浏览器自动保存。
- 字号、行距、宋体／楷体／黑体、正常／护眼／夜间、简体显示、注释展开、文白对照和批注展开。
- 手机目录及自适应布局；快捷键 Ctrl/Cmd + K 搜索。

书签、批注、设置和进度保存在当前浏览器中。清除网站数据会清除这些记录。

## 人物卡片与重名处理

主 EPUB 原文人名标记建立了 133,138 条段落出现记录。人物库包含 2,033 条人物资料：7 条人工整理的简介及公开 Wikidata 资料；各条资料附来源链接。人物索引与阅读数据均保存在本地，查阅卡片不需要联网。

人物身份以独立编号保存，不以名字作为主键。依据全名和明确生卒年关联；多位同名人物的年代同时符合时保持待辨认，不选择第一条结果。资料没有明确出生年、纪年不明或人物时代之外的出现记录，也保持待辨认。单字简称仅在同一段包含明确全名时关联；泛称“高祖”“武帝”“齐王”等不会单凭纪年直接合并。西晋王衍与前蜀王衍有独立档案，西汉末刘歆改名的刘秀与光武帝刘秀也分别保存。

尚未可靠关联的人名可以点击查看本段身份线索及前后“同名线索”，这些线索不等同于同一人物的出现记录。当前按资料及纪年关联 7,653 条记录，关联仍需要进一步史料考订，尤其是追述、引文及同段中的简称。完整的全书人物身份考订尚未完成。

人物检索范围为主 EPUB 原文人名标记，胡注内部、译文及另外两部书尚未建立点击人物索引。源书的姓名标记也包括部分称号、军队或群体名称，待辨认卡片不会把它们认定为某个人。

Wikidata 资料来源：https://www.wikidata.org/ ，下载日期 2026-10-02。使用人物编号、中文姓名与别名、生卒年及中文简述；结构化数据遵循 CC0：https://www.wikidata.org/wiki/Wikidata:Licensing 。其他整理简介的来源在各人物卡片中注明。

## 沙盘态势
每段原文旁的“沙盘态势”打开段落沙盘。左侧为原文、译文和态势记录，右侧为对应时代地图。选择旗标、行军箭头、区域框或文字，在地图上标绘；阵营提供红、蓝、绿、紫四色。移动模式支持滚轮缩放、拖动及原图大小。支持撤销、重做、单项删除；记录和标绘按段落及图幅保存在当前浏览器，可导出 JSON 沙盘文件，导入到其他浏览器。标绘位置和内容由阅读者自行录入。
